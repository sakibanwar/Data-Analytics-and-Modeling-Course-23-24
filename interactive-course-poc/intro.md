## What's New in This Interactive Version?

This interactive version of the course materials allows you to:

- **Run code directly in your browser** - No installation needed! Click the rocket icon (🚀) at the top of any page and select "Live Code" to activate interactive mode
- **Experiment with examples** - Modify any code example and see the results immediately
- **Complete exercises with instant feedback** - Get automatic checking on your solutions
- **Learn at your own pace** - All materials are available 24/7

## How to Use These Materials

1. **Read through the content** - Each week's materials explain concepts in a friendly, step-by-step manner
2. **Try the examples** - Click the 🚀 button and choose "Live Code" to make all code cells interactive
3. **Modify and experiment** - Change the code and run it to see what happens
4. **Complete the exercises** - Test your understanding with auto-graded exercises
